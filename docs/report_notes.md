# Report notes - Smart Traffic Accident Analysis and Severity Prediction

Consolidated notes for the written report (generated by `src/build_docs.py`; every number is read from
`reports/metrics/`). Author: Abin Shaji Thomas.

## 1. Problem

Find where and when US road accidents cluster, which weather / time / road conditions are linked to high traffic
impact (Severity 3-4), and how well Severity (1-4) can be predicted at report time. Severity measures delay on
traffic, not injury.

## 2. Data

* 7,728,394 records x 46 columns, 2016-01-14 to 2023-03-31; CC BY-NC-SA 4.0.
* Full-data Severity counts: 1 = 67,366; 2 = 6,156,981; 3 = 1,299,337; 4 = 204,710.
* Recorded accidents per year (full file): 2016: 410,821, 2017: 718,093, 2018: 893,426, 2019: 954,303, 2020: 1,178,913, 2021: 1,563,753, 2022: 1,762,452, 2023: 246,633
  (2016 and 2023 are partial years).

## 3. Methods and decisions

1. **Profiling** - one chunked pass (500,000 rows) over the whole file for null counts, dtypes and full-data
   State / City / hotspot-grid counts (`data_dictionary.csv`).
2. **Sampling** - 399,999 rows, same fraction (0.051757) per Severity level in every chunk,
   `random_state=42`; sample class mix equals the full mix.
3. **Cleaning** - 418 duplicate-content rows removed (0 duplicate IDs);
   13 columns dropped (constant, redundant, metadata, high-cardinality or leaky - reasons in `cleaning_log.json`);
   41 physically impossible weather values set to missing.
4. **Missing GPS** - Start GPS missing: 0, out of bounds: 0 (so the
   City+State median recovery recovered 0 and 0 rows were dropped);
   End GPS missing in 176,088 rows -> imputed from Start (point-event assumption, flag `End_GPS_Imputed`).
5. **Missing weather** - numeric -> State+Month median; categorical -> State+Month mode. The upstream rule
   "missing precipitation = 0" was tested (`precipitation_rule_test.csv`) and kept only for dry weather groups;
   precipitation was missing in 114,071 rows (28.55%).
6. **Weather groups** - 7 groups: Clear, Cloudy, Rain, Snow, Fog/Haze, Storm, Other.
7. **Outliers** - IQR counts reported; winsorized at the 0.5th / 99.5th percentiles (`outliers_winsorize.csv`).
8. **Features** - Hour, DayOfWeek, Month, Year, IsWeekend, IsRushHour, DayNight, RoadFeatureCount; Duration (EDA only).
9. **EDA statistics** - chi-square + Cramer's V (categorical), Kruskal-Wallis + epsilon-squared (numeric), Pearson
   and Spearman correlation, KMeans (k=12 by silhouette for k>=5),
   DBSCAN (haversine, eps 2.0 km, min_samples 25), 0.1-degree grid hotspots on all records.
10. **ML** - scikit-learn Pipeline + ColumnTransformer, stratified 80/20 split (319,664 / 79,917),
    class_weight='balanced', 3-fold RandomizedSearchCV on macro-F1 (full training set), runs with and without Distance.
    Excluded: End_Time, Duration (post-event), Year and Source (collection artefacts), ID, free text.
11. **Big data** - MongoDB documents with GeoJSON + 2dsphere; 10 queries timed with/without indexes; Hadoop Streaming
    mapper/reducer for 3 jobs run locally (map -> sort -> reduce); three-way cross-check.

## 4. Findings

* Severity 2 makes up 79.66% of accidents and Severity 1 only 0.87%; the largest class is 91x the smallest, so accuracy alone is misleading and macro-F1 is used in Module 4.
* Rain has the highest severe share (22.87%) vs Fog/Haze the lowest (15.81%); overall 19.47%. The link is significant (chi-square p<1e-300) but weak (Cramer's V=0.039).
* Strongest numeric weather effect: Pressure(in) (epsilon^2=0.0106); all six effects are below 0.06 (negligible/small), so single weather readings separate severity levels only slightly.
* CA, FL and TX record the most accidents (41.5% of all); top city is Miami, FL (186,768). Counts are not rates (no traffic volume).
* Densest 0.1-degree cell: around Los Angeles, CA with 50,254 accidents; the top 10 cells hold 4.6% of all accidents.
* DBSCAN (2 km, 25 points) finds 302 dense urban clusters; the largest is around Los Angeles, CA; 57.81% of accidents are outside any dense cluster.
* Strongest numeric link to Severity: Year (Spearman -0.28); strongest categorical: Source (V=0.29), then City (V=0.28).
* Peak hours are 07:00 and 16:00; a weekend day averages 53% fewer accidents than a weekday.
* Severe share falls from 33.99% in 2016 to 2.83% in 2023 while counts rise - a change in data collection, so Year is not used as an ML feature.
* Accidents near a junction are severe 26.75% of the time vs 18.9% elsewhere; near a traffic signal only 9.54% vs 21.2%.
* Median traffic-impact duration rises from 44.7 min (Severity 1) to 127.2 min (Severity 4).
* Chi-square WeatherGroup x Severity: chi2 = 1,818.5, dof = 18.

  accuracy than the baseline because class weighting shifts predictions towards rare classes; macro-F1 is the fair measure.

## 7. Limitations

* Severity = traffic impact, not injury; labels depend on the data provider and collection period.
* Counts are not rates - no traffic-volume, speed-limit or road-class data.
* Models trained on a 5.18% stratified sample with a random split; a time-based split would be stricter.
* Decision Tree probabilities are close to 0/1, so its ROC-AUC (0.6272) is low even though its macro-F1 is close to Random Forest.
* Hadoop cluster (HDFS/YARN) and Spark runs were documented but not executed (no Docker/WSL/Java on the laptop).
* The best model file (Random Forest) is larger than 50 MB and is kept locally in `models/` (not committed).
